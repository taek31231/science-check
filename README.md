# 과학 세특 활동 선택 (통합과학 · 과학탐구실험)

학생이 올해 수행평가 중 진로와 관련된 활동을 골라 제출하면(통합과학 11개(진로 맞춤 자유주제 발표 포함) 중 최대 4개, 과학탐구실험 6개 중 최대 3개),
결과가 구글 스프레드시트의 반별 탭(1-1 ~ 1-10)에 자동 기록되고 교사 4명이 그 시트에서 세특을 함께 작성하는 도구입니다.

```
학생 (GitHub Pages: index.html)  ──학번·이름·선택──▶  Apps Script 웹 앱  ──▶  구글 스프레드시트 (1-1 ~ 1-10 탭)
```

| 파일 | 역할 |
|---|---|
| `index.html` | 학생 제출 페이지 (학번+이름 본인 확인 → 체크박스 선택 → 제출/수정) |
| `config.js` | Apps Script 웹 앱 URL, 페이지 제목 |
| `apps-script/Code.gs` | 스프레드시트에 붙여 넣는 코드 (시트 자동 생성 + 제출 처리) |

---

## 설정 방법 (처음 한 번, 약 10분)

### 1단계. 스프레드시트 만들기 + 코드 붙여 넣기
1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (예: `2026 1학년 과학 세특`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고, 이 저장소의 `apps-script/Code.gs` 전체를 붙여 넣습니다.
4. 맨 위 `CONFIG` 를 수정합니다.
   - `activities` : **실제 수행평가 이름**(통합과학 11개, 과학탐구실험 6개). `desc` 에 한 줄 설명을 넣으면 학생 화면에 표시됩니다.
   - `TEACHERS` : 협업 교사 이름 (현재: 황율예, 이수영, 유자현, 임형택)
   - 통합과학 활동별 `teacher` : 해당 활동 기록 담당 교사
   - 과학탐구실험 `classTeachers` : 반별 담당 교사 (현재: 이수영 1·2·5·9반 / 유자현 3·4·10반 / 임형택 6·7·8반)
   - `STUDENTS_PER_CLASS` : 반별 최대 번호 (기본 30)
   - `REQUIRE_ROSTER` : `true` 면 교사가 입력한 명단과 학번·이름이 일치해야만 제출됩니다 (권장)
5. 저장(💾) 후, 상단 함수 선택에서 **`setupSheets`** 를 골라 **실행** → 권한 승인.
   - `현황`, `1-1` ~ `1-10`, `제출기록` 탭이 만들어집니다.

> ⚠️ 활동 이름·개수는 **setupSheets 실행 전에** 확정하세요. 이후에 바꾸려면 해당 반 탭을 삭제하고 다시 실행해야 합니다(이미 있는 탭은 건드리지 않음).
> 활동 *이름만* 바꾸는 경우에는 Code.gs 의 이름과 시트 3행의 활동명을 같이 고치면 됩니다.

### 2단계. 학생 명단 입력
각 반 탭의 **이름(C열)** 에 번호 순서대로 학생 이름을 붙여 넣습니다. (학번 칸은 학생 제출 시 자동 입력)

### 3단계. 웹 앱 배포
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
2. 실행 계정: **나**, 액세스 권한: **모든 사용자** → 배포
3. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사하여 `config.js` 의 `SCRIPT_URL` 에 넣고 커밋합니다.

> Code.gs 를 수정한 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 를 해야 학생 페이지에 반영됩니다. (URL은 그대로 유지)

### 4단계. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**.
잠시 후 `https://<계정>.github.io/science-check/` 주소가 생깁니다. 이 주소를 학생들에게 안내하세요.
(비공개 저장소의 Pages 는 유료 플랜이 필요하므로 공개 저장소를 권장합니다. 페이지에는 학생 정보가 없습니다.)

### 5단계. 교사 공유
스프레드시트를 교사 4명에게 **편집자**로 공유합니다.

---

## 학생 사용 흐름
1. 학번 5자리(예: 1학년 3반 5번 → `10305`) + 이름 입력 → **확인** (명단과 다르면 거부)
2. 희망 진로(선택), 통합과학 최대 4개 / 과학탐구실험 최대 3개 체크 (한도를 넘으면 나머지 체크박스가 잠김)
3. 제출 → 완료 화면. 마감 전까지 다시 들어와 **수정 가능** (이전 선택이 불러와짐, 마지막 제출이 반영)

마감하려면 `CONFIG.OPEN = false` 로 바꾸고 새 버전으로 배포하세요.

## 스프레드시트 구성

### 반별 탭 (1-1 ~ 1-10) — 한 행 = 학생 한 명
| 영역 | 내용 |
|---|---|
| 번호 · 학번 · 이름 · 희망 진로 · 제출 일시 | 학생 제출 시 자동 기록. 미제출 학생은 이름이 분홍색 |
| 활동별 **[선택 ☑ \| 활동 기록 \| 바이트]** | 통합과학은 활동명 아래에 기록 담당 교사가 표시됩니다. 과학탐구실험은 탭 제목에 반 담당 교사가 표시되고 담당 교사 칸이 자동으로 채워집니다.<br> 학생이 고른 활동은 체크 + 기록 칸이 **노란색으로 활성화**. 고르지 않은 활동의 기록 칸은 **회색이며 입력이 거부**됩니다. (교사가 체크박스를 직접 켜면 활성화) 바이트 칸에는 그 활동 기록의 나이스 바이트가 자동 계산됩니다. |
| 선택 수 | 자동 |
| 세특 초안 | 선택된 활동의 기록 칸을 자동으로 이어 붙임 |
| 초안 바이트 | 1500B 초과 시 빨간색 |
| 세특 최종본 | 교사가 다듬어 작성 (초안을 복사해 붙여 넣고 수정) |
| 최종 글자수 · 최종 바이트 · 판정 | `✅ 120B 남음` / `⚠ 35B 초과` |
| 담당 교사 · 진행 상태 | 드롭다운 (미착수 / 작성중 / 검토요청 / 수정필요 / 완료) |
| 비고 | 교사 간 메모 |

통합과학, 과학탐구실험이 각각 블록으로 나뉘어 있고 바이트는 **과목별로** 계산됩니다. 수식 열과 머리글은 실수로 지우려 하면 경고가 뜹니다.

### 나이스 바이트 계산 기준
- 한글·한자·특수기호 등(비ASCII): **3바이트**
- 영문·숫자·공백·기본 문장부호: **1바이트**
- 줄바꿈(Enter): **2바이트**

```
=LEN(t)+2*LEN(REGEXREPLACE(t,"[\x00-\x7F]",""))+(LEN(t)-LEN(SUBSTITUTE(t,CHAR(10),"")))
```

### 시트 형식 업데이트 (코드 변경 후)
열 구성이 바뀐 코드를 붙여 넣었다면 메뉴 **세특 도구 → 기존 탭을 최신 형식으로 업데이트 (데이터 유지)** (또는 `migrateClassSheets` 실행)를 누르세요. 명단·제출 내용·교사 기록을 그대로 옮겨 새 형식으로 다시 만듭니다. 업데이트 전에는 학생 제출이 잠시 거부됩니다.

### 현황 탭
- 반별 명단 인원 · 제출 수 · 제출률 · 과목별 완료 수 · 바이트 초과 수 · **미제출 학생 명단**
- **교사별 활동 기록 현황**: 교사마다 학생이 선택한 담당 활동이 몇 건이고, 그중 '활동 기록' 칸을 채운 건수·남은 건수·진행률
- **활동별 선택 인원**: 활동마다 선택 인원 · 기록 완료 · 남은 기록 (전체 반 합계)
메뉴 **세특 도구 → 현황 탭 다시 만들기** 로 언제든 재생성할 수 있습니다.

### 제출기록 탭
모든 제출/수정 이력이 시간순으로 쌓입니다 (신규/수정 구분).

## 참고
- 본인 확인은 **학번 + 명단 이름 일치** 방식입니다. 다른 학생의 학번과 이름을 아는 경우까지 막지는 못하므로, 제출기록 탭에서 '수정' 이력을 확인할 수 있게 해 두었습니다.
- 학생 페이지는 Apps Script 에서 활동 목록을 받아오므로, 활동 이름은 `Code.gs` 한 곳에서만 관리하면 됩니다.
